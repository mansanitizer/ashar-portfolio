01 / COMPLIANCE & BUSINESS STRATEGY

Enabling Mutual Funds Pivot Through Digital KYC

regulatory requirement & business need

As part of our strategic pivot to mutual funds, KYC compliance became mandatory for user onboarding. The existing manual process was creating significant friction in user acquisition and time-to-value delivery.

I led the design and implementation of a digital KYC system to allow users to complete onboarding in minutes rather than hours, while ensuring full regulatory compliance for mutual fund investments.

  • Compliance Mandate: KYC required for all mutual fund transactions to meet regulatory standards
  • User Acquisition: Streamlined onboarding to improve conversion and reduce drop-off rates
  • Time to Value: Fast user verification to allow immediate investment capability
02 / TECHNICAL EXECUTION & INTEGRATION

Building Seamless Digital Identity Verification

integration challenges

Coordinated complex third-party integrations while managing technical constraints and ensuring smooth user experience across the verification flow.

  • HyperVerge Integration: OCR and liveness detection to allow instant document verification
  • CVL KRA Integration: KYC record access and validation to improve onboarding accuracy
  • Technical Bandwidth: Managed integration complexity with limited engineering resources during pivot period

product delivery & impact

Successfully launched digital KYC system that transformed user onboarding experience while maintaining regulatory compliance:

  • Engineering Collaboration: Worked closely with dev team to manage multiple API integrations and error handling
  • User Experience Design: Simplified multi-step verification process to improve completion rates
  • Strategic Planning: Prioritized core verification features to allow faster go-to-market during company pivot
  • Business Impact: Reduced onboarding time from hours to minutes, significantly improving user acquisition metrics
